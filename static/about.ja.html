書g-sho

このサイトについて

g-sho は、jisho.org に影響を受けて作られた和英・英和辞書です。静的サイトとして作られており、辞書データはビルド時に何千もの小さなファイルに分割されています。ブラウザは検索のたびに必要な部分だけをダウンロードします。検索した内容がほかの場所へ送られることはありません。

データの出典

データは以下のプロジェクトのもので、jmdict-simplified の JSON 版を通じて利用しています。各ライセンスでは出典の表示が求められており、EDRDG のファイルについては、派生データを同じライセンスで公開することも求められています。

検索のしくみ

  • 日本語の単語は、完全一致と前方一致で検索します。活用した動詞や形容詞（食べました、高かった）は、活用のルールにもとづいて辞書形にさかのぼって検索します。
  • ローマ字はかなに変換し、英語と合わせて検索します。
  • 英単語は、設定で、日本語での説明（英和）や英語の語釈も表示できます。変化形からは元の単語が引けます（went → go、walked → walk）。
  • 手書き文字は、書いた文字の画像から、ブラウザ内で動くニューラルネットワークが認識します（WebGPU、WebGPU が使えない環境では WebAssembly）。画数・筆順・書く向きは問いません。
  • 写真の中の文字（カメラボタン）は、さらに 2 つのニューラルネットワークがブラウザ内で見つけて読み取ります（WebGPU、WebGPU が使えない環境では WebAssembly）。1 つが横書き・縦書きの文字の行を見つけ、もう 1 つが各行を読み取ります。カメラの映像や写真が端末の外に出ることはありません。
  • 文章は、各位置で辞書にある最も長い単語を探すことで単語に区切ります。一部の辞書が使っている形態素解析器よりも単純な方法のため、まれに間違った位置で区切ることがあります。
