プライバシー

g-sho はアカウントなしで使えます。その場合、検索・履歴・設定はお使いのブラウザの中にだけ保存されます。辞書は検索に合わせて小さな単位でダウンロードされ、入力した内容がどこかへ送られることはありません。手書き文字や、カメラ・写真からの文字の読み取りもブラウザ内で行われます。書いた文字、カメラの映像、写真が端末の外に出ることはありません。

ログインした場合

ログインは任意です。Google、GitHub、LINE、またはパスキーでログインでき、次の情報を保存します。

  • Google の場合：ログイン時に受け取る Google アカウント ID（数字）とお名前。Google に求めるのはこれだけで、メールアドレスやその他の情報は求めません。
  • LINE の場合：ログイン時に受け取る LINE のユーザー ID と表示名。LINE にメールアドレスやその他の情報は求めません。
  • パスキーの場合：パスキーの ID と公開鍵、付けた名前、作成日時と最終使用日時。パスキーの秘密の部分が、お使いの端末やパスワードマネージャーの外に出ることはありません。パスキーだけでアカウントを作るときは、Cloudflare Turnstile が人間による操作かどうかを確認します（Turnstile のプライバシーポリシー）。
  • GitHub の場合：公開されている GitHub プロフィールから読み取る GitHub のユーザー ID（数字）、ユーザー名、表示名。GitHub にメールアドレスやその他へのアクセスは求めず、GitHub のアクセストークンはプロフィールを読み取った直後に破棄します。
  • ログインセッションごとの記録（開始日時と有効期限）。セッションはブラウザの 1 つの Cookie に保持され、こちらではそのハッシュ値だけを保存します。

ログイン中は、このサイトが端末間で同期する内容も保存します。検索履歴、スターを付けた単語や「覚えた」にした単語、単語へのメモ、表示の設定、そして学習用のデッキ（カードと復習履歴を含む）です。読み込んだ Anki デッキの画像や音声は、読み込んだ端末の中にだけ残ります。Anki との接続設定も、それぞれの端末に残ります。

広告、アクセス解析、トラッキング用の Cookie は一切ありません。データを販売したり、共有したりすることもありません。

あなたのデータ

設定 → アカウント から、アカウントに保存されているすべてのデータをダウンロードしたり、アカウントを削除したりできます。削除すると、そのアカウントに保存されていたものはすべて、ただちにデータベースから消去されます。ブラウザに保存されている内容は、ご自身で消去するまで残ります。

ホスティング

g-sho は Cloudflare 上で動いています。ほかのウェブホストと同様に、Cloudflare はリクエストを処理し、サービスの運用と保護のために、IP アドレスを含むログを短期間保存することがあります。詳しくは Cloudflare のプライバシーポリシー をご覧ください。
