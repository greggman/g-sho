利用規約

g-sho は、個人が趣味で作っている無料の日本語辞書です。ここでは、利用にあたっての約束ごとをわかりやすい言葉でまとめています。

あなたのデータ

私たちはあなたのデータに関心がありません。販売も共有もせず、広告を表示することも、追跡することもありません。何をなぜ保存しているかは、プライバシーのページに書いてあります。

Google、GitHub、LINE でログインするとき、メールアドレスやその他の連絡手段は求めません。受け取るのは ID とお名前だけです。パスキーの場合は、それよりもさらに少なくなります。そのため、こちらからメールを送ることはできませんし、送ることもありません。

設定 → アカウント から、アカウントに保存されているすべてのデータをダウンロードしたり、アカウントを削除したりできます。

保証はありません

g-sho は現状のまま提供され、いかなる保証もありません。辞書の内容を含め、間違いがあるかもしれません。停止したり、変更されたり、データが失われたりすることもあります。大切なものは、ご自身でもコピーを保管してください（データをダウンロード は 設定 → アカウント にあります）。

g-sho の運営、またはアカウントや同期の提供は、いつでも停止することがあります。特に、悪用されて運営の負担が大きくなった場合はその可能性があります。その場合は、データをダウンロードできるよう、事前にサイト上でお知らせするよう努めますが、お約束はできません。

法律で認められる範囲で、g-sho を利用したこと、または利用できなかったことによるいかなる損失や損害についても、責任を負いません。

禁止事項

  • アカウントを大量に作成すること、ログインを自動化すること
  • サイトに大量のリクエストを送りつけること、サイトや他人のアカウントへの侵入を試みること
  • 違法なものの保存に使うこと

これらを行うアカウントは削除し、アクセスはブロックすることがあります。事前の通知は行いません。

自分で動かす

g-sho は MIT ライセンスのオープンソースです。このサイトがなくなった場合や、このサイトに頼りたくない場合は、ご自身でコピーを動かせます。コードは GitHub にあります。辞書データはほかのプロジェクトのもので、それぞれのライセンスが適用されます。このサイトについて・データの出典をご覧ください。

変更

この規約は変更されることがあります。最新版は常にこのページに掲載しています。変更後も g-sho を使い続けた場合は、新しい規約が適用されます。
